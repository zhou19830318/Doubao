📡 完整对话数据流

从用户说出唤醒词到听到 AI 回复的完整链路。每一步标注组件和线程。

⬆️ 上行（用户 → 服务器）

①
🎤 麦克风采集
audio_in.c → board_audio_record()
16kHz/16bit 单声道，每帧 640 samples (40ms)
线程: doubao_cap (core 1, prio 9)
②
📦 入队（12帧环形缓冲）
PSRAM 环形队列，溢出丢最旧帧
dbaudio_in_dequeue() 被发送任务消费
③
🧠 VAD 判停
vad.c — 自适应噪声底
16帧校准 → 6dB阈值 → 静音1.5s判停 / 15s上限
返回 VAD_SILENCE → 触发 commit
④
📤 Base64 编码 + 发送
proto_build_audio_append()
PCM → Base64 → JSON 文本帧 → WebSocket
线程: doubao_send (core 1, prio 8)
⑤
✋ commit（判停信号）
proto_build_commit()
告诉服务器：用户说完了，请开始生成

⬇️ 下行（服务器 → 设备）

⑥
📝 ASR 转写流
transcript.delta → 气泡显示用户文本
transcript.completed → 完整转写
⑦
💬 LLM 文本生成
output_text.delta → 气泡流式追加
output_text.done → 完整回复保存
⑧
🔊 TTS 音频流
output_audio.started → 启动播放
output_audio.delta → Base64 解码 PCM
⑨
🎼 重采样 24kHz → 16kHz
resampler.c — 3:2 多相滤波
3相×4抽头 Kaiser 窗，低延迟高音质
⑩
🔈 扬声器播放
audio_out.c → 64KB PSRAM 环形缓冲
board_audio_play() → I2S TX
线程: doubao_play (core 1, prio 10)
output_audio.done → response.done → 自动续听

🔀 打断（Barge-in）机制

本地能量检测

播放期间，每 100ms 比较麦克风 RMS 和播放 RMS：

mic_rms > play_rms × 2（6dB margin）
持续 80ms（2 ticks）→ 触发本地打断

设备立即：
• 发送 response.cancel 到服务器
• 停止播放（20ms fade-out 防爆音）
• 回到 LISTENING 状态
• 服务器返回 response.canceled

服务器端打断

用户在播放期间说话 → 服务器检测到新的语音输入：

返回 input_audio_transcription.started
设备收到后：
• 停止当前播放
• 进入 LISTENING 等待新内容

注意：打断期间 VAD 仍在运行，
新的 commit 会自动发送。

📖 快速开始

1️⃣

首次开机配网

设备开机后自动进入 AP 配网模式。屏幕显示 WiFi 配置 QR 码。
用手机扫描 QR 码 → 自动连接 Doubao_Config 热点 → 浏览器弹出配置页。
在网页上填写：WiFi 密码、豆包 API Key、音色、提示词等。

2️⃣

日常使用

设备连接 WiFi 后自动进入待机（绿色 LED + 时钟显示）。
唤醒方式：说"你好小智" / 单击屏幕 / 按 BOOT 键。
设备进入聆听（红色脉冲），说完后自动发送给 AI，等待回复。

3️⃣

连续对话

默认开启自动续听：AI 回复后自动继续聆听。
静默 8 秒后自动回到待机。
可在网页设置中关闭自动续听（单轮模式）。

4️⃣

打断回复

AI 正在说话时，你可以直接开口打断。
设备检测到你的声音后自动停止播放，开始新一轮对话。
也可以在播放中触摸屏幕打断。

❓ 常见问题

Q: 设备一直显示 "连接中..."？

A: 检查 API Key 是否正确。打开串口监控查看日志。确认 WiFi 已连接（LED 绿色）。


Q: 能听到 AI 说话但我说话它没反应？

A: 可能是麦克风增益太低。检查 ES7210 麦克风 I2C 地址 (0x40) 和 I2S RX 配置。


Q: 屏幕不亮 / 花屏？

A: LCD SPI DMA buffer 需要内部 RAM。检查 draw buffer 大小（5-10行）和 MALLOC_RESERVE_INTERNAL 设置。


Q: 扫描 QR 码后手机没有自动连接？

A: 确保设备处于 AP 模式（LED 闪烁）。部分手机需要确认连接开放网络。也可手动连接 Doubao_Config。

I2S 音频链路

单 I2S 总线（port 1），TX/RX 共享时钟：

• 采样率：16kHz（收发一致）
• 位深：16bit
• TX：SLOT_BOTH（立体声功放）
• RX：SLOT_RIGHT（ES7210 mic 数据在右槽）
• bit_shift=true, left_align=true
• DMA：80-150ms 缓冲

关键约束：同一 I2S 外设的 TX/RX 共享时钟，收发采样率必须一致。运行中变速一律软件重采样。
